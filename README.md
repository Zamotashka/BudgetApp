# BudgetApp
### Учебный проект — практика Git (ветки, слияние, история коммитов)

Консольное приложение для учёта личного бюджета (C#).

## Функциональность

- Категоризация доходов/расходов
- Учёт транзакций (класс `Transaction`)
- Управление бюджетом (класс `BudgetManager`)
- Сохранение и загрузка записей из txt-файла
- Юнит-тесты для основных классов и UI

## Практика разработки

Проект вёлся с отдельной веткой под фичу и слиянием обратно в
основную ветку (видно на графе коммитов: ветка расходится 8 апреля
и позже сливается обратно). По ходу разработки добавлялись тесты
(`BudgetManager`, `Transaction`, `Form1`), фиксировались и
исправлялись найденные баги (например, некорректная работа с
датой, возможность сделать бюджет отрицательным).
